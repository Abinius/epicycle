本文件由人工实测填写，数字都可复现（方法写在每节里）。

## 一、首屏体积

**方法**：`npm run build`，取 vite 输出的 gzip 体积。

| 产物 | 原始 | gzip | 是否阻塞首屏 |
| --- | --- | --- | --- |
| `index.js`（主入口） | 341.4 KB | **114.4 KB** | 是 |
| `index.css` | 16.9 KB | **4.3 KB** | 是 |
| **首屏合计** | | **≈ 119 KB** | |
| `FormulaPanel.js`（KaTeX） | 262.5 KB | 78.9 KB | 否，点开公式面板才加载 |
| `FormulaPanel.css` | 29.8 KB | 8.0 KB | 同上 |
| `worker.js` | 27.4 KB | — | 否，起 Worker 时加载 |
| `mp4-muxer.js` | 30.7 KB | 8.9 KB | 否，点导出才加载 |
| `gifenc.js` | 9.0 KB | 3.9 KB | 否，同上 |
| `browser.js`（fflate） | 5.1 KB | 2.3 KB | 否，同上 |
| KaTeX 字体 | 60 个 woff2/ttf | — | 否，按需取用；其中一个小于阈值被内联为 data URI |

**结论**：预算 300 KB，**首屏 ≈119 KB，余量充足**。

- 真正阻塞首屏的只有主入口 + 一份 CSS。公式面板（KaTeX，占大头）、导出链路三个库、采样 Worker 全部是动态 import 的独立 chunk。
- 若按「打开页面后迟早会加载」的口径，加上 KaTeX 与公式面板 CSS 是 ≈206 KB，仍在预算内。
- M6 加进来的一堆东西（多语言词典、L3 序列内核、无障碍与快捷键、隐私对话框）让主入口 gzip 从 103.9 涨到 114.4 KB，仍只有预算的四成。

⚠️ **两个口径别混**：CI 的体积门禁卡的是 `dist/assets` 下**全部** js+css 的 gzip 之和（≈224 KB），不是真首屏。它把懒加载的 KaTeX、导出链路与 Worker 一起算进去了——门禁偏保守是好事（一收紧懒加载 chunk 也会红），但跟「首屏」不是一回事，写文案时别把 224 说成首屏。

## 二、性能基准

**方法**：Node 24（V8，与 Chromium 同引擎族）跑真实 `core/` 模块，各预热一次后取均值。
**注意**：Node 是热 JIT，浏览器冷启动会明显慢些；这些数字用于判断「离预算有多远」，不是端到端实测。

| 指标 | 预算（技术文档 §11） | 实测 | 余量 |
| --- | --- | --- | --- |
| 采样 N=2048（签名曲线，镜像回扫） | < 50 ms | **1.0 ms** | 50× |
| DFT N=2048 | < 300 ms | **0.5 ms** | 600× |
| 单帧渲染 K=200，1280×720 | < 8 ms | **4.2 ms** | 1.9× |
| 首屏 JS gzip | ≤ 300 KB | **≈108 KB** | 2.8× |

补充实测（浏览器端，Playwright + msedge）：

- 导出 12 帧 720p H.264（WebCodecs）端到端 **约 2 秒**（含建 Worker、探测能力、封装 MP4）。
- 窗口 320×640 下页面无横向溢出，画布宽度 > 280 px。

## 三、数值样张结果表

样张全部落在 `src/core/__tests__/` 里，随 CI 跑，任何一项不达标即失败。

| 编号 | 断言 | 阈值 | 结果 |
| --- | --- | --- | --- |
| V-1 | 单位圆只有 n=1 非零 | 其余 \|cₙ\| < 1e-12 | ✅ |
| V-2 | 方波奇次谐波（由分析谱构造的带限信号） | 相对误差 < 1e-9 | ✅ |
| V-2′ | 直接采样 ±1 方波的精确闭式解 `c_n = 2/N − (2i/N)cot(πn/N)` | 1e-11 ~ 1e-12 | ✅ |
| V-3 | 心形重建（N=1024 / K=200） | RMS < 0.5 % 峰值 | ✅（实测 ~1e-13，心形解析上带限于 \|n\| ≤ 4） |
| V-4 | 负频率叉积（±n 不合并） | 精确 | ✅ |
| V-5 | 线性相位斜坡 = 时间平移 | 差 < 1e-10 | ✅ |
| V-6 | 渲染纯度：同一 (场景, t, 选项) 两次调用绘制序列完全相同 | 逐条相等 | ✅ |
| 附 | Gibbs 过冲（方波 K 截断） | 台阶相对过冲 9 ± 1 % | ✅ |

对文档口径的两处更正（PRD 数字未改，测试注释里写明了）：

1. PRD 的「方波相对误差 < 1e-9」只对**由分析谱构造的带限信号**成立；直接采样 ±1 方波的精确解是 `2/N − (2i/N)cot(πn/N)`，与朴素的 `2/(πn)` 差 1e-3 量级。两条都写了测试。
2. 「心形 K=200 可辨认」近乎平凡——经典心形是次数 4 的三角多项式，1024 个系数里只有 8 个 > 1e-12。K 的作用要在宽带形状（方波、真实签名）上才看得出。
